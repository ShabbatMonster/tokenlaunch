Bonding curve. A poz.fun / Pons v2 token has no DEX pool at all until it graduates — the only liquidity is the launch curve, which holds the whole float. Terminals that find markets by scanning DEX factories see nothing and call the token untradeable; it is not. If the token names a curve that has not graduated, that curve is offered directly via its own buy / sell. Two things are surfaced that you cannot see elsewhere: the live snipe tax (starts near 99% and decays to zero over the first few seconds — buying into it is close to a total loss), and the real exit liquidity, which is the quote the curve actually holds rather than its mostly-virtual reserve. Selling past that reverts with a bare arithmetic panic, so it gets translated into plain language.

long.xyz / portfolio.market zap. The opposite problem: the pool exists and is deep, but it is not quoted in anything you hold. A portfolio coin is paired against its own numeraire — LONGfolio trades against L8NG, an 8-token basket vault that has no ETH pool anywhere — so routers that only know ETH-quoted pools find no way in. There is one. The vault names a minter(), which is really their Register: it wraps, mints the vault token and swaps the v4 pool in a single call, taking plain ETH. That route is derived and then checked, never assumed — the Airlock names the numeraire and the pool hook, the numeraire names the zap, and the zap is only used once its coin() and VAULT() point back at the exact token and numeraire you asked for. The underlying v4 pool is offered too, for anyone already holding the numeraire.

lightoor.fun. A third shape of “no market”. These sit on a bonding curve, but quoted in whatever the creator picked — often one of lightoor's own leveraged tokens. LIGER is quoted in xLIT5L (“LIT 5x Long”), which has no pool on any DEX and which you cannot mint or redeem yourself: the LT factory answers NotZap() to every caller but their zap. So a token quoted in one looks completely unreachable. Two routes are offered — the launchpad directly if you already hold the quote token, and the zap, which settles the same curve in USDG and mints or redeems the leveraged quote token inside the call. For an LT-quoted token the zap is the only way in or out, so it is listed first. Quotes here are exact and need no approval: previewBuy / previewSell are plain view functions.

Five venues are searched for every token. Abyss pools route through the same router the reference trade used (). Any pool on that factory works, not just WETH ones — USDG-quoted and token/token pools are traded directly via exactInputSingle, while WETH pools use the native-ETH entrypoints so you spend and receive plain ETH. The pool key (profile / flag / extra) is read from the factory creation event rather than guessed.

Uniswap v4 pools — where the bonding-curve pads (Pons v2, poz.fun) land a token after it graduates — route through the Universal Router (). v4 has no per-pool contract and this chain's RPC rate-limits log scans, so the pool is found by rebuilding its PoolKey from the token itself (curve().pairToken() for the quote, launchFactory().memeHook() for the hook) and reading the PoolManager's storage directly — a pool that reads back a non-zero price is proven to exist, not assumed. Selling into a v4 pool needs two one-time Permit2 approvals, which the SELL button handles for you.

Every swap on every venue is simulated first to get the real output before your slippage is applied as the minimum.
