DEVELOPER DETAILS 

    

  


  
Pons v2 tokens launch on a bonding curve and graduate into a live Uniswap v4 pool once the curve's WETH reserve hits its threshold. Graduation is normally triggered by Pons's executor bot; if it doesn't happen, the factory exposes a permissionless rescue path after a delay. This tool only ever simulates first — it will never show an action it can't actually verify on-chain.
